# Auto Exam — тренажер ПДР України

Інтерактивний тренажер на 299 питань: 9 порцій, змішані набори, закладки, випадковий порядок відповідей і режим «Найчастіші помилки».

Сайт: `https://marynashavlak.github.io/auto-exam/` (після ввімкнення GitHub Pages).

## GitHub Pages

Завантажте файли цього каталогу в корінь гілки `main`, потім відкрийте Settings → Pages → Source: Deploy from a branch → Branch: main → Folder: /(root) → Save.

Прогрес зберігається локально в браузері (localStorage), а не в GitHub.

Коментарі до питань, збережені питання й найчастіші помилки можна синхронізувати між пристроями: кнопка «☁️ Синхронізація між пристроями» під питанням → токен GitHub із дозволом `gist`. Дані зберігаються в секретних gist цього акаунта; на кожному пристрої вводиться той самий токен. Прогрес проходження порцій не синхронізується.
